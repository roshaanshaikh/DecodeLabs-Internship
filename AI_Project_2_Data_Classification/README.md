# AI Project 2 - Data Classification Using AI

## Project Overview
A supervised learning classification project using the Iris dataset.

## Algorithm Used
- K-Nearest Neighbors (KNN)

## Workflow
1. Load dataset
2. Split training and testing data
3. Apply feature scaling
4. Train classification model
5. Predict results
6. Evaluate using accuracy and confusion matrix

## Requirements
Install libraries:

pip install scikit-learn

## Run

python classification_model.py
