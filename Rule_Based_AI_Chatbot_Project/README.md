# Rule-Based AI Chatbot 🤖

## Project Overview
A simple rule-based chatbot developed using Python.

## Features
- Greeting handling
- AI related responses
- Exit command
- If-else decision making
- Continuous conversation loop
- Unknown input fallback

## Technology Used
- Python

## How to Run
python chatbot.py

## Example Commands
hello
what is ai
your name
help
exit
