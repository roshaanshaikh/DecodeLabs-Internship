# AI Project 3 - Recommendation System

## Overview
A content-based AI recommendation system that maps user skills with suitable technology career paths.

## Method Used
- TF-IDF Vector Mapping
- Cosine Similarity
- Ranking and Top-N Recommendation

## Features
- Takes user skills as input
- Converts skills into vectors
- Calculates similarity score
- Displays top 3 recommendations

## Run
pip install scikit-learn

python recommendation_system.py
